02 / تجربة العمل

الفكرة أوّلاً.
والتفاصيل بمكانها.

تصميم يقرّبك من مهمتك: تعرف أين تبدأ، وأين تجد مشروعك، وكيف تراجع النتيجة.

  1. 01

    ابدأ بما تحتاجه

    اكتب طلبك وحدّد الملفات أو تفاصيل المشروع.

  2. 02

    راجع أثناء العمل

    تابع النتيجة، ووضّح المطلوب عندما تحتاج المهمة إلى ذلك.

  3. 03

    احتفظ بالقرار

    راجع التغييرات قبل اعتمادها، خصوصاً في الأعمال المهمة.

03 / للمطوّرين

من اختيار النموذج
إلى أول طلب.

النماذج والمفاتيح والرصيد في مسار واحد. اطّلع على السعر والقدرات قبل أن تختار.

افتح منصة المطوّرين ↗اقرأ التوثيق
cURLAPI / v1
# Choose an active model ID from the OPTES API (GET /v1/models)
curl https://api.optes3.com/v1/chat/completions \
  -H "Authorization: Bearer $OPTES_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "<model-id>",
       "messages": [{"role": "user", "content": "Hello"}]}'

مثال اتصال. ضع معرّف نموذج فعّال من OPTES API مكان <model-id>.
